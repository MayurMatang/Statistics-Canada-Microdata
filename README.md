# Statistics-Canada-Microdata
Analysis of Canadian Internet Use Survey 2022 using R

Statistics Canada's survey microdata uses weights to compute point estimates and for standard errors it uses bootstrap weights. This project shows how to setup a survey design object and conduct descriptive analysis, inferential analysis and modeling using R. I used the microdata of 'Canadian Internet Use Survey 2022' for this project.

Link to download data from the official website: https://www150.statcan.gc.ca/n1/pub/56m0003x/2020001/2022.zip
